MAER CHAT — RELEASE NOTES

VERSION 0.5.3 — 27 AUGUST 2026

- Fixed message bubbles collapsing after repeated Android layout passes.
- Kept direct-chat avatars in the header by default and grouped room avatars.
- Protected lock-screen notifications with a generic public version.
- Added linked-device retry, expiration, replay protection and precise errors.
- Added interoperable MAER call invitations restricted to meet.jit.si.
- Added real Android screen capture through the existing WebRTC video track.
- Tightened deep links, accessibility and navigation tests.

The Maer Chat client remains free software under GNU GPL version 3 or any later
version and can be used with compatible XMPP servers. An active paid account is
required only to access messaging servers operated by MAER Engineering under
the applicable service contract.
